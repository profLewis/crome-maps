WorldCereal

Summary

Global 10m crop type maps from ESA, specifically mapping temporary cropland, maize, winter cereals, and spring cereals. Uses Sentinel-1/2 imagery with a deep learning approach. Designed for food security monitoring with seasonal updates. First global 10m crop-specific maps.

CoverageGlobal
Resolution10m (Sentinel-1 + Sentinel-2)
Temporal2021 (seasonal)
LicenseCC-BY 4.0

Description

WorldCereal produces global crop type maps at 10m resolution, focusing on temporary crops (as a group), maize, winter cereals, and spring cereals. Uses a combination of Sentinel-1 SAR and Sentinel-2 optical time series processed through a deep learning classifier. Maps are produced per agro-ecological zone per growing season.

Provenance

Produced by a consortium led by VITO for ESA. Classification uses a convolutional neural network trained on global reference data from multiple sources including LPIS, CDL, and crowd-sourced labels.

Classification System

4 products: Temporary Crops (all annual crops), Maize, Winter Cereals (wheat, barley, rye, triticale), Spring Cereals.

Accuracy & Validation

Temporary crops: 88% overall accuracy globally. Maize: 82% F1 score. Winter cereals: 80% F1 score. Performance varies by region — highest in Europe and North America, lower in tropical smallholder systems.
