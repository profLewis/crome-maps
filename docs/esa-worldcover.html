ESA WorldCover

Summary

Global 10m land cover map from ESA, classifying 11 land cover types using Sentinel-1 and Sentinel-2 imagery. Available for 2020 and 2021. The highest resolution global land cover product freely available, providing crucial cropland extent information worldwide.

Description

ESA WorldCover provides global land cover classification at 10m resolution using both Sentinel-1 SAR and Sentinel-2 optical data. The 11 classes include cropland, tree cover, shrubland, grassland, built-up, bare/sparse vegetation, snow/ice, water, wetland, mangroves, and moss/lichen. Produced by a consortium led by VITO.

Provenance

Produced by VITO/Brockmann Consult/CS/Gamma/IIASA/WUR for ESA. Classification uses a catboost classifier trained on ~50,000 global training samples from IIASA's LACO-Wiki platform. Input: annual Sentinel-1/2 composites.

Classification System

11 classes: Tree cover (10), Shrubland (20), Grassland (30), Cropland (40), Built-up (50), Bare/sparse vegetation (60), Snow/ice (70), Water (80), Wetland (90), Mangroves (95), Moss/lichen (100).

Accuracy & Validation

Global overall accuracy of 74.4% (2020 v100). Cropland class achieves 78.2% producer accuracy and 84.3% user accuracy globally. Higher accuracy in regions with large, homogeneous fields (North America, Europe).
