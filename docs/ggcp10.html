GGCP10 — Global Gridded Crop Production

Summary

Global gridded crop production data at 10km resolution for major crops including maize, wheat, rice, and soybean. Provides spatially explicit production quantities (tonnes) by combining harvested area, yield, and satellite data. Useful for understanding global food production patterns and hotspots.

Description

GGCP10 provides gridded estimates of crop production (in tonnes per grid cell) for major crops worldwide. The dataset combines national/subnational production statistics with satellite-derived cropland maps to spatially distribute production. Useful for identifying production hotspots, food security analysis, and trade modeling.

Provenance

Derived from FAO statistics, national data, and satellite-derived crop distribution maps. Production = Harvested Area × Yield, spatially disaggregated using MODIS-derived crop masks as allocation weights.

Accuracy & Validation

National totals are constrained to FAO statistics. Subnational accuracy depends on input data quality. Grid-cell estimates are more reliable in data-rich regions (North America, Europe) than in data-sparse areas.
