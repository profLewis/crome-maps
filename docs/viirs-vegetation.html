VIIRS Vegetation Indices (NDVI & EVI)

Summary

Global 8-day composite vegetation indices from the VIIRS sensor on Suomi NPP, providing NDVI and EVI at 375m resolution. Successor to MODIS vegetation products with improved spatial resolution and radiometric quality.

CoverageGlobal
Resolution375m
Temporal2025–present (8-day composites)
LicensePublic domain (US Government work)

Description

VIIRS (Visible Infrared Imaging Radiometer Suite) vegetation index products continue the legacy of MODIS vegetation monitoring with improved capabilities. NDVI (Normalized Difference Vegetation Index) measures overall vegetation greenness. EVI (Enhanced Vegetation Index) provides improved sensitivity in high-biomass tropical regions and reduces atmospheric and soil background effects. Both are 8-day composites using maximum value compositing.

Provenance

NASA EOSDIS via GIBS (Global Imagery Browse Services). Sensor: VIIRS on Suomi NPP satellite.

Classification System

Continuous index values: NDVI (-1 to 1), EVI (-1 to 1). Higher values indicate denser vegetation.
