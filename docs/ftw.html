Fields of The World (FTW)

Summary

Global field boundary dataset covering 24 countries, providing individual agricultural field delineations for machine learning training and benchmarking. Contains ~1.6 million field polygons from diverse agricultural systems worldwide. Designed as a benchmark dataset for field boundary detection from satellite imagery.

Coverage24 countries (global sample)
ResolutionField parcel level (vector polygons)
TemporalVarious (2018-2023)
LicenseCC-BY 4.0

Description

Fields of The World aggregates field boundary data from national open data sources across 24 countries spanning diverse agricultural landscapes. The dataset is designed for training and evaluating machine learning models for automatic field boundary delineation from satellite imagery. Countries range from large-field systems (USA, Argentina) to smallholder agriculture (Vietnam, Rwanda, Kenya).

Provenance

Compiled by Clark University and partners. Source data from national LPIS/cadastral systems, open geospatial platforms, and crowd-sourced mapping. Each country's data is standardized to a common schema with field boundary polygons.

Classification System

Binary: field boundary / non-boundary. No crop type information.

Accuracy & Validation

FTW is a reference/benchmark dataset, not a classification product. The field boundaries are derived from authoritative national sources (LPIS, cadastral data). Boundary accuracy depends on the source country's system — typically <5m in European LPIS data, variable in developing country datasets.
