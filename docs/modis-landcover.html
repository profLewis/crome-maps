MODIS Land Cover (MCD12Q1)

Summary

Global 500m annual land cover classification from the MODIS instrument, providing the longest consistent satellite land cover time series (2001-present). Uses the IGBP classification with 17 land cover types including croplands and cropland/natural vegetation mosaic. The reference dataset for global land cover change analysis.

CoverageGlobal
Resolution500m

Description

The MODIS Land Cover Type product (MCD12Q1) provides annual global land cover maps at 500m resolution. The product includes five classification schemes; the IGBP scheme (default) includes croplands (class 12) and cropland/natural vegetation mosaic (class 14). Uses supervised classification of MODIS reflectance data with ancillary information.

Provenance

Produced by Boston University under NASA funding. Input: MODIS Terra+Aqua reflectance, land surface temperature, and EVI time series. Classification: ensemble decision tree (C5.0) trained on global training sites. Post-processing: temporal consistency filtering using prior-year map.

Classification System

IGBP 17 classes including: Croplands (12), Cropland/Natural Vegetation Mosaic (14), plus forest, shrubland, grassland, wetland, urban, barren, water, snow/ice classes.

Accuracy & Validation

Overall accuracy ~75% for IGBP 17-class scheme. Cropland class achieves ~82% accuracy. Higher accuracy at coarser aggregation levels. Well-validated through multiple independent assessments over 20+ years.
