Probabilistic Crop Type Map (1km)

Summary

Global 1km maps showing the probability of each major crop type being grown in each grid cell. Provides crop type shares (%) for wheat, maize, barley, rapeseed, sunflower, and grassland, plus a dominant crop type layer. Derived from statistical disaggregation of agricultural census data weighted by satellite observations.

CoverageGlobal (best in Europe)

Description

The probabilistic crop type maps show the fractional area of each crop type within each 1km grid cell. Unlike binary classification maps, these capture the mixed nature of agricultural landscapes. The dominant crop layer shows which crop has the highest share in each cell. Share layers show the percentage (0-100%) of each individual crop.

Provenance

Derived from national LPIS/IACS data and CORINE Land Cover, disaggregated onto a 1km grid using entropy maximization. Method similar to CROPGRIDS but focused on European crop types at higher resolution.

Classification System

6 crop types: Wheat (SWHE), Maize (MAIZ), Barley (BARL), Rapeseed (RAPE), Sunflower (SUNF), Grassland (GRAS). Values represent share (0-100%) per grid cell.

Accuracy & Validation

Validated against LPIS data in selected countries. R² values of 0.7-0.9 for dominant crops at 1km scale. Best performance for wheat and grassland (large, widespread crops), lower for minor crops.
