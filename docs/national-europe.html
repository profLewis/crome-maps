European National LPIS / Crop Maps

Summary

Agricultural parcel and crop type datasets from individual European countries, derived from their national Land Parcel Identification Systems (LPIS) / Integrated Administration and Control Systems (IACS). These field-level datasets provide the highest-quality crop information available, as they are tied to EU subsidy declarations and verified by national agencies. Countries include: Netherlands (BRP), Belgium (Flanders/Wallonia), Austria (INVEKOS), Denmark (FVM), Luxembourg (ASTA), Portugal (IFAP), Switzerland (BLW), Norway (NIBIO), Germany (FLIK), France (RPG), Spain (SIGPAC), Slovenia (GERK), Croatia (ARKOD), Estonia, Latvia, Sweden, Finland.

Description

Each EU member state maintains a Land Parcel Identification System (LPIS) as part of the Integrated Administration and Control System (IACS) for Common Agricultural Policy (CAP) payments. Many countries publish anonymized versions of their LPIS data as open data. These datasets contain individual field polygons with crop type declarations, providing ground-truth-quality crop information at field scale. Key national datasets in the viewer: - Netherlands BRP: ~800K parcels/year, 300+ crop codes - Belgium Flanders (ALV): Detailed field parcels with crop declarations - Belgium Wallonia: SIGEC agricultural parcels - Austria INVEKOS: Federal agricultural parcel register - Denmark FVM: Marker (field) data with crop codes - France RPG: Registre Parcellaire Graphique, ~6M parcels - Germany FLIK: Feldblockkataster reference parcels (state-level) - Portugal IFAP: iSIP agricultural parcels - Norway NIBIO AR5: Land resource map including agricultural areas - Spain SIGPAC: Geographic Information System of Agricultural Parcels

Provenance

Each dataset is produced by the respective national paying agency responsible for CAP implementation. Data collection: farmer self-declaration combined with remote sensing verification (CwRS) and on-the-spot checks. Published as open data by national geoportals or EU-level aggregators.

Classification System

Each country uses its own crop nomenclature, which maps to the HCAT taxonomy in EuroCrops. Common classes across countries: cereals (wheat, barley, maize), oilseeds (rapeseed, sunflower), root crops (potatoes, sugar beet), protein crops (beans, peas), fodder (clover, alfalfa), permanent grassland, permanent crops (fruit, vineyards).

Accuracy & Validation

LPIS/IACS data represents the gold standard for crop type information, as it is based on farmer declarations tied to subsidy payments and verified by national agencies. Geometric accuracy varies: GNSS-based systems achieve <2m, while photo-interpretation based systems may have 5-10m. Crop type accuracy >95% for major crops.

LPIS data is used as training and validation data for satellite-derived crop maps (EuroCrops, JRC EU Crop Map, HRL Crop Types). It is not independently validated in the same way as remote sensing products — rather, it IS the reference data.
